昨日秩父へ行った疲れのせいか、はたまた気の早い五月病をもたらす疫病神のせいか、セミナーの準備をする気力も起きず、今日は一日中寝込んでしまった。

とは言え何もせず寝ていたのではなく、ブローアップの例外因子について考え込んでいた。ブローアップに対する典型的な説明として、特異点を解消する１つの手法である、というものがある。例えば$C = \{ x^{3} + y^{3} + xy = 0 \}$といった、原点でnodeを持った平面曲線を原点でブローアップすると、$C$の原点における2本の傾きの異なる接線が分離されるためにそのnodeが解消される、といったものである。この場合の例外因子$E$は、分離された2本の接線に対応する2点集合となる。

一般の状況を思い出そう。$Y$をスキームとし、$X$をその閉部分スキームとしたとき、$Y$の$X$に沿ったブローアップ$ \pi : \widetilde{Y} \to Y$は、$X$を定義するイデアル層を$ \mathcal{I} $としたとき、$ \widetilde{Y} := Proj \bigoplus _{n = 0}^{\infty} \mathcal{I} ^{n}$ として定義されるのであった。そして$ \widetilde{Y}$の例外因子$E$とは、逆像$\pi ^{-1} (X)$のことであった。

上の例の観察から、$E$は$X$上のバンドルのようなものであり、各ファイバーは"ブローアップにより分離されるべきもの"である、と思うことができそうである。ではこの"分離されるべきもの"とは一体何なのだろうか。平面曲線の場合の1点でのブローアップでは、"その点での接線"である、と言えそうである（正確にはやや異なると今は理解しているが、それは後の話）。ただ、一般の状況では全てが高次元のため、幾何的に想像ができず苦しんでいたのである。

では、どうやって理解を得たかといえば、$E$を定義通り計算しただけである。初めからそうすればよかったのだが、ブローアップの定義が若干複雑であるのもあって、無意識に恐怖心を感じていたのかもしれない。数学を学んでいく以上、こういった感情からは早く離脱したいものであるが、今回それを自覚できただけでも収穫だろうか。

さて、実は計算しようと思ってしまえばあっけない話で、$E$のイデアル層は$X$のそれから誘導されるので、$E = Proj \bigoplus _{n = 0}^{\infty} \mathcal{I} ^{n} / \mathcal{I}^{n+1}$となる。これは、もしも$X$が$Y$のregular subschemeであったとすると，本当の意味で射影束となり、$E = \mathbb{P} ( (\mathcal{I} / \mathcal{I}^{2})^{\vee} )$となる。故に、$E$は$(\mathcal{I} / \mathcal{I}^{2})^{\vee}$ を束ねているわけだが、ではこれが何かといえば、$X$の$Y$内におけるnormal bundleである。$\mathcal{I} / \mathcal{I}^{2}$は、$Y$内における$X$の接平面のなす空間なので、その双対として、"normal vector"を表していることは、幾何的にも見て取れる。当然、一般の場合は射影束にはならず、torsionが現れてくる。

このことから、ブローアップが分離しているのは、"$X$の$Y$の中におけるnormal vactor達"であると言える。そう考えてみると、例えばeffective cartier divisorに沿ったブローアップが何も変えないことは、ある意味自明であると理解できそうである。

以上のことはあくまでも私なりの考えであって、全くの見当違いである可能性も否定できないので、ぜひ皆さんの意見も聞きたいです。
